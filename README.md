# DropScale

Make valuable loot stand out. A client-side Fabric mod for Minecraft **1.21.11**.

## Download

[Download the compiled mod](https://github.com/082-0/DropScale/releases/latest)

Only compiled mod downloads are published here. No Java source code is published.

## Install

Install Fabric Loader 0.18.1 or newer, Fabric API 0.141.6+1.21.11 or newer, and Java 21 or newer. Put the DropScale JAR into your Minecraft instance's mods folder.

Press **O** to open the UI. You can change this under **Options > Controls > Key Binds > DropScale**.

## Features

- Search all registered nonempty items by name or identifier, including modded items.
- Item icons and individual dropped-item size sliders from 0.25x to 8x.
- Glint controls: Natural, On, or Off.
- Dark UI, customizable accent color, and master On/Off button.
- Saved settings and per-item reset.

Changes affect dropped-item visuals on your client. Pickup range and collision boxes remain unchanged.

## Compatibility and testing

This build targets **1.21.11 exactly**. Later versions require separate builds. Compilation, development Minecraft startup, UI rendering, search, and saving were verified. Dropped-item world gameplay and compatibility with third-party mod packs still need testing.
